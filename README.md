# HairShaderCinematicShading
Shader Graph to add color to your Unity Hair System. Also, you can experiment with the little monkey head from the previous tutorial. 

# Youtube video shows you how to import the shader graph to your Unity project. <a href="https://youtu.be/TKs2qSbsD_U"> Click here </a>

# Step to Import the Shader Graph:

### 1. Create a High Definition 3d project in Unity
![01](https://github.com/user-attachments/assets/94e80775-659f-4793-b340-0cbf6513a716)

### 2. Add the Alembic packages
![02](https://github.com/user-attachments/assets/00944dc1-58dc-4a1c-bc41-580e6e4ae739)

### 3. Copy the URL for Unity Hair System packages (https://github.com/Unity-Technologies/com.unity.demoteam.hair) 
![03](https://github.com/user-attachments/assets/798b89f7-a41f-435d-9c94-a8b11507953f)
### 3.1 Paste the URL and click on install
![04](https://github.com/user-attachments/assets/892bd339-bc7a-4244-bb03-82ebd32212ec)

### 4. Now download the shader graph to change the color for the hair
  ![06](https://github.com/user-attachments/assets/cac5e26d-ebd1-4e48-9d7d-694f7ae29cc8)
### 4.1 Extract the packages and click on import. Look for the HairShaderCinematicShading.unitypackages
  ![07](https://github.com/user-attachments/assets/57fc8855-9f5f-4576-bcc3-8ca5a3e1b751)
### 4.2 Look for the HairShaderCinematicShading 
  ![08](https://github.com/user-attachments/assets/07617aa6-4901-448c-9b5c-822883f70247)
### 4.3 Click on the Hair Object and expand the setting rendering. Add the material.    
  ![11](https://github.com/user-attachments/assets/6d0c9bf9-59d0-4bcf-9c0c-02feb7cda95a)
### 5. Now have fun and change the colors. 
  ![12](https://github.com/user-attachments/assets/62b19562-3d2d-4e6c-b614-c7e21db84681)
